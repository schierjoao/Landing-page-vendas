Landing Pages de vendas

## 🧩 Funcionalidades

✅ Layout moderno e responsivo (mobile first)  
✅ Botão de compra com redirecionamento direto para o WhatsApp  
✅ Animações suaves com efeito *fade-in* ao rolar a página  
✅ Estrutura otimizada para SEO e performance  
✅ Seções inspiradas em páginas reais de e-commerce:  
- Destaque do produto  
- Preço e condições de pagamento  
- Avaliações de clientes  
- Descrição detalhada
